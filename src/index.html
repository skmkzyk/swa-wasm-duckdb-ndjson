🦆 NDJSON Log Viewer

Powered by DuckDB WASM - Fast analytical queries on your log files

📁
Drop your NDJSON file here or click to browse
Supports .ndjson, .jsonl, .gz files from App Service console logs
Supports SAS URLs, direct blob URLs, and wildcards: e.g. https://account.blob.core.windows.net/logs-xxxxx-net/y=2026/m=01/d=20/h=09/m=00/*.ndjson.gz?sv=...&ss=...&srt=...&sp=rl&se=...
Select a container to load all ndjson.gz files for today. The API will generate a secure, read-only SAS token.
